# SmartFurni

**AI-Powered Furniture Recommendation and Room Planning System**

SmartFurni is a furniture platform designed to help users explore furniture products, discover suitable options, and plan their living spaces.

## Features

- Furniture browsing and product discovery
- User-friendly interface
- Furniture recommendations
- Room planning experience
- 3D visualization support
- Product and category management
- User and admin workflows

## Technology Stack

### Frontend
- React.js
- JavaScript
- Tailwind CSS
- Three.js
- React Three Fiber
- Axios
- Recharts
